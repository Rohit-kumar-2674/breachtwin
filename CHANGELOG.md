# Changelog

## 0.1.0 — 2026-09-16

- Added a three-case FastAPI access-control lab with vulnerable and corrected behavior.
- Added strict JSON contracts, explicit actor headers, and environment references for credentials.
- Added positive controls, setup checks, evidence predicates, and inconclusive outcomes.
- Added recorded evidence with runtime metadata and SHA-256 integrity checks.
- Added contract replay and exportable unittest regressions.
- Added offline mobile-friendly reports with search, filters, trace inspection, and evidence download.
- Added a CLI, a read-only loopback report viewer, documentation, and CI configuration.

This alpha executes explicit local contracts. Automatic vulnerability discovery, patch generation, OS sandboxing, and hosted services are not included.
